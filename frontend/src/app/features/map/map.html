Fonte: varredura .NET dos arquivos appsettings*.json dos repositórios analisados; o ambiente de cada ligação vem do arquivo de origem (appsettings.Hom.json é hom). As ligações do arquivo base ou de um ambiente desconhecido aparecem em todos os ambientes, como "base". O destino de cada endereço é decidido por uma pessoa na tela Integrações: sem decisão, vai para o nó "Sem app".
