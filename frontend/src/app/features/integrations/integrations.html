Integrações

Os endereços que os repositórios catalogados declaram chamar, segundo a última análise de cada um (hoje lidos dos arquivos appsettings*.json). Um host com {{ '{env}' }} é um modelo: o ambiente só se sabe pelo arquivo. Quem diz a que app do catálogo cada host pertence é uma pessoa: abra um host e confirme ou rejeite o app, ou marque vários hosts na lista e decida todos de uma vez. Host de serviço que não está no catálogo pode ser marcado como externo. Um vínculo feito no modelo {{ '{env}' }} vale para dev, hom e prod. A análise roda no terminal (CheckApps.Analyze).

Vale um trecho do host, sem diferença de maiúsculas e minúsculas. Em branco, lista todos.
